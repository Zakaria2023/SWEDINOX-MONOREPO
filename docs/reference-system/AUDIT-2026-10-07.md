### Bugs found on the way

- `dateRangeFilter` crashed on every timestamp column (`toISOString is not a
  function`) — fixed centrally.
- Raw-SQL timestamps were read as local time — `timestampFromDriver`.
- `Stock (€)` computed as kg × price ÷ 1000 is wrong for a lot priced per
  piece — the stock overviews read the stored `valuationEuro`.
- Both supplier revenue screens valued purchases at the lot's valuation
  price × the invoiced quantity and called the quantity kilos.
- Nesting, Production capacity details and Reoptimize composed `Order type`
  from the pick-up / consignment ticks, the same bug as Orders and quotes.
- Trip data read `TransportTrips`, which nothing writes.
